# Contributing

Thanks for taking a look. Issues and pull requests are welcome.

- Run `npm ci`, then `npm run typecheck`, `npm test` and `npm run build` before you open a pull request. CI runs the same.
- Keep a change small and say what it fixes. A change to the wire protocol (`docs/protocol-v1.md`) or to the presentation contract (`contract.json`, `docs/presentation-contract.md`) needs a note in `CHANGELOG.md`.
- **Sign off your commits** (`git commit -s`). That adds a `Signed-off-by:` line and means you agree to the [Developer Certificate of Origin](https://developercertificate.org/): you wrote the change, or you have the right to submit it under this project's MIT license.
