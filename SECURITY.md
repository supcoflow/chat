# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Use GitHub's private vulnerability reporting for this repository (Security tab → "Report a vulnerability").

Include what you found, how to reproduce it, and the version of `@supcoflow/chat` you tested. We'll acknowledge the report and tell you what we plan to do about it.

## Scope

This repository contains the `@supcoflow/chat` package: the embeddable chat widget, the framework-free core, the React hook and the local demo server (`supcoflow-chat-fake`, which only listens on `127.0.0.1` by default).
The hosted service is a separate system; if you find a problem there, report it the same way and mention it.
